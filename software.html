Software e sistemas

Entenda os sistemas que coordenam o computador, os programas que usamos e as ferramentas para criá-los.

1 SISTEMAS OPERACIONAIS

Um sistema operacional é um software responsável por controlar o funcionamento do computador, organizar os arquivos e permitir que os programas sejam executados. Exemplos: Windows, Linux e macOS.

1.1 Sistemas livres

Sistemas livres são sistemas operacionais que permitem aos usuários acessar, estudar, modificar e distribuir seu código-fonte, respeitando os termos de sua licença.

1.1.1 Linux

Linux é um sistema operacional livre e de código aberto, conhecido por sua segurança, estabilidade e flexibilidade. É utilizado em computadores, servidores e outros dispositivos.

Distribuições

Distribuições Linux são versões do sistema Linux que incluem o núcleo do sistema e diferentes programas e ferramentas. Exemplos: Ubuntu, Debian, Fedora e Linux Mint.

1.2 Sistemas proprietários

Sistemas proprietários são sistemas operacionais controlados por empresas ou organizações, que definem as regras de uso, modificação e distribuição do software.

1.2.1 Apple

A Apple é uma empresa de tecnologia que desenvolve sistemas operacionais, como o macOS, utilizado em computadores Mac, e o iOS, utilizado em iPhones.

1.2.2 Microsoft

A Microsoft é uma empresa de tecnologia conhecida pelo desenvolvimento do Windows, um dos sistemas operacionais mais utilizados em computadores pessoais e empresariais.

2 SOFTWARES

Software é o conjunto de programas, instruções e dados que permitem ao computador realizar tarefas. Exemplos: navegadores, editores de texto, jogos e sistemas operacionais.

2.1 Tipos de licenças

As licenças de software estabelecem as regras para utilizar, copiar, modificar e distribuir um programa. Elas determinam os direitos e as limitações dos usuários.

2.1.1 Licenciados

Softwares licenciados são programas utilizados de acordo com uma licença que autoriza seu uso e estabelece condições específicas. Dependendo da licença, pode ser necessário pagar para utilizá-los.

2.1.2 Livres

Softwares livres permitem que os usuários executem o programa, estudem seu funcionamento, modifiquem seu código e distribuam cópias, respeitando as condições da licença. Software livre não significa necessariamente gratuito.

2.1.3 Proprietários

Softwares proprietários possuem restrições definidas por seus titulares. Geralmente, o código-fonte não fica disponível para o público, e a utilização depende das condições estabelecidas na licença.

2.2 Tipos de softwares

Os softwares podem ser classificados conforme sua finalidade. As principais categorias são softwares de sistema, aplicativos e softwares de programação.

2.2.1 de Sistemas

Softwares de sistema controlam o funcionamento do computador e permitem que os outros programas sejam executados. Exemplos: Windows, Linux e drivers de dispositivos.

2.2.2 Aplicativos

Softwares aplicativos são programas desenvolvidos para ajudar os usuários a realizar tarefas específicas, como escrever textos, navegar na internet, editar imagens e fazer cálculos. Exemplos: Word, Excel e Google Chrome.

2.2.3 de Programação

Softwares de programação são ferramentas utilizadas para criar, testar e corrigir outros programas. Exemplos: Visual Studio Code, compiladores e ambientes de desenvolvimento.

2.3 Software para diagnóstico

Softwares de diagnóstico são programas que ajudam a identificar problemas, verificar o funcionamento e avaliar o desempenho de um computador e de seus componentes.

2.3.1 Diagnóstico de software

O diagnóstico de software consiste em verificar programas, sistemas operacionais e configurações para encontrar erros, falhas, incompatibilidades ou problemas de desempenho.

2.3.2 Diagnóstico de hardware

O diagnóstico de hardware consiste em verificar os componentes físicos do computador, como memória RAM, disco de armazenamento, processador e placa-mãe, para identificar possíveis defeitos.

2.4 Ferramentas de Busca e Download

Ferramentas de busca e download ajudam a localizar informações, programas, arquivos e atualizações na internet e permitem baixá-los para o computador. É importante utilizar fontes confiáveis para evitar arquivos maliciosos.

2.4.1 Plugins

Plugins são componentes adicionais que ampliam as funções de um programa ou sistema. Eles permitem adicionar recursos que não estão disponíveis na instalação original.

2.4.2 Complementos do navegador

Complementos do navegador são extensões que adicionam funcionalidades ao navegador de internet, como bloqueio de anúncios, tradução de páginas e gerenciamento de senhas.

2.4.3 Versão de software

A versão de um software identifica uma edição ou atualização de um programa. As novas versões podem corrigir erros, melhorar a segurança, aumentar o desempenho e adicionar recursos.

2.4.4 Filtros de busca

Filtros de busca são recursos que ajudam a refinar os resultados de uma pesquisa, permitindo selecionar informações por data, tipo de arquivo, idioma, período ou outras características.
